# 📊 Super Store Power BI Dashboard

## 📌 Project Overview
This project is a **Power BI dashboard** built using the **Super Store dataset**.  
The dashboard provides clear insights into **sales, profit, customer segments, categories, regions, and trends over time** to support data-driven business decisions.

---

## 🎯 Objectives
- Analyze **total sales and total profit**
- Identify **most profitable categories and sub-categories**
- Understand **profit distribution by region and customer segment**
- Track **profit trends over multiple years**

---

## 🛠 Tools & Technologies
- **Power BI**
- **Excel (Data Source)**
- **Data Cleaning & Modeling**
- **DAX (basic measures)**

---

## 📈 Dashboard Highlights
- **Total Sales:** 2.30M  
- **Total Profit:** 286.40K  
- **Top Category by Profit:** Technology  
- **Top Region by Profit:** West  
- **Top Segment:** Consumer  

### Visuals Included:
- Profit by Category
- Profit by Sub-Category
- Profit by Region
- Profit by Customer Segment
- Profit Trend by Year
- Interactive State & Category Filters
